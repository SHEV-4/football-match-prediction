# Football Match Prediction

Проєкт для збору футбольної статистики та підготовки датасету, на якому буде навчатися модель передбачення результату матчу. Дані збираються з [WhoScored](https://www.whoscored.com/) за допомогою Selenium, а керувати збором можна через невеликий застосунок з графічним інтерфейсом на PySide6.

> **Статус:** проєкт у розробці. Зараз готовий етап збору й підготовки даних, модель ще не побудована.

## Що збирається

Команди п'яти ліг: **La Liga, Premier League, Serie A, Bundesliga, Ligue 1** (96 команд).

| Група | Показники |
|---|---|
| Summary | голи, удари, жовті та червоні картки, володіння м'ячем, точність передач, виграні єдиноборства в повітрі, рейтинг |
| Defensive | удари проти за матч, відбори, перехоплення, фоли, офсайди |
| Offensive | удари у площину воріт, успішні дриблінги, фоли на команді |
| xG | xG, різниця xG, усього ударів, xG на удар |
| Турнірна таблиця | матчі, перемоги, нічиї, поразки, забиті та пропущені голи, різниця, очки |
| Форма | кількість перемог, нічиїх і поразок в останніх 6 матчах (`wins_6`, `draws_6`, `losses_6`) |
| Результати матчів | господарі, гості та результат: `2` перемога господарів, `1` нічия, `0` перемога гостей |

## Як це працює

1. Парсер відкриває Chrome, збирає статистику команд і турнірні таблиці та зберігає їх у CSV: `whoscored_stats.csv`, `whoscored_leagues_standings.csv`, `whoscored_combined.csv`.
2. Окремо парсер збирає результати матчів обраного тижня (`whoscored_match_result.csv`).
3. Статистику команд поєднують з результатами матчів. Для кожного матчу виходить один рядок з ознаками господарів (`home_*`) та гостей (`away_*`) і цільовою змінною `match_result`. У підсумковому датасеті 67 стовпців.
4. Датасет використовується для побудови моделі в Jupyter-ноутбуку.

## Запуск

Потрібні Python 3 і браузер Google Chrome. Проєкт розроблено на Python 3.14.

```bash
git clone https://github.com/SHEV-4/football-match-prediction.git
cd football-match-prediction
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cd app
python app.py
```

У вікні програми:

1. Натисни **Вибрати папку** і вкажи, куди зберігати CSV-файли.
2. **Результати команд** збирає поточну статистику команд і таблиці ліг.
3. **Результати матчів за минулий тиждень** збирає результати останнього завершеного тижня.
4. **Результати матчів за конкретний тиждень** відкриває вибір діапазону дат. Парсер гортає календар назад, поки не знайде потрібний тиждень (до 60 кроків).

Хід роботи виводиться в журнал у нижній частині вікна.
